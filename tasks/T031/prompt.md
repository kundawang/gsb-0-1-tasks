给我做个给数字电路课学生用的小工具：连好线之后能跑时钟，看每个节点电平怎么变。我们用一套很小的器件集合，
不用做复杂模型。

器件：输入开关 IN、与/或/非门 AND/OR/NOT、异或 XOR、D 触发器 DFF、输出灯 OUT。连线单向，AND/OR/XOR 可多输入，
NOT/DFF/OUT 各一个输入。时钟是离散的：每个 tick 所有器件都拿"上一 tick 的输出"当输入，一起结算
（同步更新，不要按连线顺序传播）。DFF 在上升沿把 D 锁进 Q，初始 Q=0。

要能做的事：

- 从 JSON 电路描述加载：器件列表（id/type/可选参数）+ 连线列表 + IN 初始值
- 单步、连续跑 N 个 tick、重置回初始状态
- 每步输出所有节点（器件输出 + 连线）的电平快照；界面上按时序图画最近 50 个 tick
- 检出组合环（比如 NOT 自己接自己）：加载时就报错并指出环上的器件，别让它跑起来

硬指标：

1. 纯逻辑（加载、环检测、单步结算、快照生成）要能脱离 DOM 在 `node --test` 里直接调。
2. 同步更新必须是真同步：同一 tick 内一个器件的变化不能影响本 tick 其他器件的输入。
   测试里用一条 3 级串联电路验证（不这样做的话会瞬间穿透，最容易写错）。
3. 环检测用拓扑排序，报错信息里给出环上的器件 id，顺序稳定（同一份输入结果一致）。
4. 非法输入要明确报错：未知器件类型、连线指向不存在的器件、DFF 缺时钟线、端口号越界。
5. 数字只能是 0/1；输入 JSON 里出现别的值按非法处理。
6. 界面：器件用 SVG 画，连线可点选高亮；时序图纵轴节点、横轴 tick，tick 用等宽格子。

约束：纯静态 —— 原生 ES module + HTML/CSS，不引构建、不装依赖、不联网；纯逻辑放在单独模块里。
samples/ 里我放了两个电路（多数表决、4 位计数器），你按它们跑通就行。README 写清楚怎么跑、怎么测。

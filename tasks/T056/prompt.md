质检抽样的判定现在靠查表，想做成工具：给批量、检验水平和 AQL，算出抽样方案并给批结论。

模型（data/aql_table.json 是简化抽样表：批量区间 × AQL 等级 → 样本量与 Ac/Re）：

- 输入：批量 N、检验水平（normal/tightened，简化成两套表）、AQL 等级（0.65/1.5/2.5/4.0）
- 抽样：按抽样表查样本量 n 与接收数 Ac、拒收数 Re（Re = Ac + 1）
- 判定：抽取 n 件里发现 d 件不合格 → d ≤ Ac 接收；d ≥ Re 拒收
- 记录：每批要留 {批号, N, n, Ac, AQL, d, 结论, 时间}，并支持按批号追溯
- 连续拒收：连续 3 批拒收 → 自动提示转加严检验（tightened）；连续 5 批接收 → 恢复 normal

要做的：

1. 纯逻辑：plan(N, level, aql)（查表，返回 n/Ac/Re 与命中的表项）、judge(plan, d)（结论）、
   trace(batchId)；全部可单测。
2. 查表要能处理边界：批量正好等于区间端点、AQL 不在表里（报错并列出可用等级）、
   批量大于表里最大档（按最大档并在结果里说明）。
3. 检验水平的自动切换要按批次顺序演进，并输出切换历史；同一批号重复录入要拒绝。
4. 抽样量 n 不能超过批量 N：若查表 n > N，改成全检（n = N）并在结果里说明。
5. 确定性：同一批输入跑两次，判定与切换历史完全一致。

界面：录入面板（批量/AQL/不合格数）+ 结论卡片（接收/拒收 + 依据）+ 批次台账表 + 水平切换历史。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写抽样表来源与判定规则。

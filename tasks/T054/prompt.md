每月盘点差异对账太费时间，想做个工具：账面和实盘一比，自动分类差异并生成调整单。

模型（samples/stock_book.csv 是账面、samples/stock_count.csv 是实盘）：

- 两边字段：sku、名称、单位、数量、货位；实盘可能多出账面没有的 sku（新入库没记账），
  账面也可能有实盘没有的（丢了）
- 差异分类规则：
  1. 两边都有、数量不同 → 盘盈（实 > 账）或盘亏（实 < 账）
  2. 只有账面有 → 疑似丢失（要按货位分组统计）
  3. 只有实盘有 → 疑似未入账
  4. 数量相同但货位不同 → 货位差异（要给出两边货位）
  5. 任一数量为负数或非整数 → 数据异常，不参与差异统计但要单独列出
- 调整单：按差异分类给出建议调整数量（盘盈盘亏按差值；丢失按账面数量取负；未入账按实盘数量取正），
  并给一个需要人工复核的标记（差异数量 > 该 sku 数量的 10% 或 > 20 件）

要做的：

1. 纯逻辑：CSV 解析（按表头匹配、容忍列顺序与前后空格）→ 对账 → 分类 → 调整单 → 报告。
2. 报告：总 sku 数、匹配数、各分类计数与金额（CSV 里有单价就按单价算金额，没有就跳过金额并说明）。
3. 边界：空文件、只有一边有数据、sku 重复（取最后一条并记录）、数量带单位（"12 个"要能解析）、
   货位为空。
4. 确定性：同一份输入跑两次结果一致；调整单按 sku 排序稳定。

界面：差异看板（分类卡片 + 数量/金额合计）+ 明细表（可筛选分类）+ 导出调整单 CSV。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写分类判定顺序与复核口径。

我们几个朋友玩桌游，算分老吵架，想做个计分器：规则可配置、能撤销、能看历史。

模型（data/rules.json 是计分规则，samples/rounds.json 是一局样例）：

- 玩家：2~8 人，每人一个名字与颜色
- 计分规则（可配置）：
  - 正分项目：自定义若干计分项（名称 + 是否加倍）
  - 负分项目：可以标记为"扣分"（计入时取负）
  - 加倍：某个计分项对某玩家加倍（比如"下一轮得分 ×2"）
- 操作：每轮录入每个玩家各计分项的原始分，系统算出本轮得分与累计分

要做的：

1. 纯逻辑：`addRound(state, round)`、`undo(state)`（至少 20 步）、`standings(state)`（含并列处理）、
   `history(state)`（每轮的明细与累计快照），全部可单测。
2. 并列处理：分数相同时按"最后一轮得分高者优先"，再按加入顺序；要写进 README 并测试。
3. 加倍规则：加倍项按 (原始分 × 2) 计；如果同一玩家同一轮有多个加倍项，各自独立加倍。
4. 边界：同一玩家同一项重复录入（要拒绝或取最后一条，二选一并说明）、
   撤销到第一轮之前（拒绝并保持状态）、玩家中途加入（从加入轮开始计分）、分数为负数。
5. 输出：当前排名表（名次/玩家/累计/本轮）、每轮明细表、最高分与最低分差。

界面：顶部玩家条（颜色 + 累计分）、中间录入表格（每轮一行）、右侧排名与历史；
按钮：加一轮、撤销、重置、导出 JSON。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写规则配置格式与并列口径。

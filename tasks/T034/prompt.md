想做个迷你电子表格：只做我们自己用的那点功能，但公式引擎要靠谱（Excel 那套引用和循环引用我踩过坑）。

界面：一个可编辑网格（行列都按 A/B/C… 和 1/2/3… 编号），单元格里可以填数字、文本、或者 `=` 开头的公式。
编辑一个格子要立刻把依赖它的单元格一起重算。

公式要求（只用这些就够）：

- 单元格引用：`A1`、`B2`；区域引用：`A1:B3`
- 数字、文本（用引号）、加減乘除（`+ - * /`）、括号、比较（`> < >= <= = <>`）
- 函数：`SUM`、`AVG`、`MIN`、`MAX`、`COUNT`、`IF(条件, 真值, 假值)`、`CONCAT`
- 错误传播：除零 → `#DIV/0!`，区域含非数字 → 该值按 0 参与 SUM/AVG 但 COUNT 不计；类型不对 → `#VALUE!`
- 循环引用：A1 = B1、B1 = A1 时两个格子都显示 `#CYCLE!`，并且要能指出环上的所有格子

硬指标：

1. 求值内核是纯逻辑（解析 → 依赖图 → 拓扑重算），必须能在 `node --test` 里直接测，不碰 DOM。
2. 重算只重算受影响的格子（改 A1 不该把没关系的格子也重算）：测试里用调用计数验证。
3. 依赖解析要处理：区域引用展开、重复引用去重、大写/小写列名等价、非法引用（`A0`、`AA`、`1A`）报 `#REF!`。
4. 每次重算的结果必须确定：同一批编辑操作序列，跑两次结果一致（格子显示值 + 错误类型 + 重算次数）。
5. 数字精度按 IEEE 双精度显示，最多保留 6 位小数；整数不要显示成 `3.000000`。

附加：能导出/导入整个表格 JSON（含公式原文与计算值），导入后重算结果与导出前一致；
支持撤销最近 20 步编辑。

约束：原生 ES module + HTML/CSS，不引构建、不装依赖、不联网；samples/sheet.json 是一个含公式的样例表。
README 写清楚支持的语法、错误码含义、怎么跑测试。

健身房器械老被占，想做个时段预约：按半小时一格，用户约器械、取消、候补。

模型（data/machines.json 是器械清单，samples/bookings.json 是预约/取消事件）：

- 器械：id、名称、同一时刻可容纳人数（默认 1，跑步机那种可以设 2）
- 时段：每天 06:00-22:00，半小时一格（共 32 格）；预约按"日期 + 起始格 + 连续格数"（1~4 格）
- 冲突：同一器械同一格已被占满就不能再约；把自己的一格拆成两段预约是允许的
- 候补：满员时进候补队列（同格位 FIFO）；有人取消时按候补顺序自动补位
- 每人每天最多 2 个预约（跨器械累计），超过要拒绝并说明

要做的：

1. 纯逻辑：回放事件（预约/取消/查询）→ 输出每一步的占用表（器械 × 时段）、候补队列、拒绝原因。
2. 取消要释放格位并触发候补自动补位；补位也要计入该用户当日配额。
3. 边界：跨天预约（不允许，报错）、格数超限、起始时间不在营业时段、同一用户重复提交同一预约（幂等）。
4. 输出统计：每台器械的占用率（按格算）、候补转正次数、当日被拒次数与原因分类。

界面：矩阵表（行=器械、列=时段，点击预约/取消，已占用格显示用户名缩写），侧面显示候补队列。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写清时段换算与配额规则。

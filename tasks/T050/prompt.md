气象站的数据导出经常有缺测和脏值，想做个清洗工具：补缺、换单位、剔异常，最后给清洗报告。

模型（samples/raw_readings.csv 是原始导出，data/config.json 是站点与阈值配置）：

- 字段：timestamp（ISO）、temp_c（摄氏）、humidity（%）、pressure_hpa、wind_ms（米每秒）、rain_mm
- 清洗规则：
  1. 单位统一：温度统一摄氏（若某些行标了 temp_f 就换算），风速统一 m/s（标了 wind_kmh 就除 3.6）
  2. 范围校验：湿度 0~100、气压 850~1100、风速 0~60，越界记为无效
  3. 异常剔除：同一站点 3 小时滑动窗口内温度偏离中位数 3σ 以上 → 记为可疑（不是直接删）
  4. 缺测插值：连续缺测 ≤ 3 个点用线性插值；> 3 个点保持空缺并记录
- 输出：清洗后的数据 + 每行的处理标记（ok / converted / clamped / suspect / missing / interpolated）+ 报告
  （各标记计数、每站缺测率、被剔除/插值的时段列表）

要做的：

1. 纯逻辑：CSV 解析、规则应用、插值、报告生成都要能单测（`node --test`），不碰 DOM。
2. CSV 解析要能处理：引号包裹、字段里有逗号、CRLF、末尾空行、列顺序不同（按表头匹配）、
   重复时间戳（保留最后一条并记录）。
3. 边界：全为空文件、只有表头、单点数据（无法算 3σ）、跨天缺测、时间戳非严格递增（先排序并记录）。
4. 同一份输入跑两次，清洗结果与报告逐字段一致。

界面：上传/粘贴 CSV → 表格展示（按标记着色）→ 报告面板 + 导出清洗后 CSV（Blob）。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写清洗规则与标记含义。

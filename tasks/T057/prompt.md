实验室配液一直手算，想做个配比反算工具：给目标含量和原料规格，算出每种原料称多少。

模型（data/ingredients.json 是原料及其有效含量，samples/targets.json 是几个配方目标）：

- 原料：名称、有效成分含量（%）、杂质约束（比如不得含氯）、最小/最大可称量（g）、单价（元/kg）
- 目标：最终总重（g）、各有效成分的目标含量（g 或 %）、pH 目标范围
- 计算：由目标含量除以原料含量得到理论用量；再按约束取整到 0.1g；
  无法满足（原料不够纯 / 超过最大可称量 / 缺少某种原料）要给出原因和最近可行方案（差多少）

要做的：

1. 纯逻辑：solve(target, ingredients) → { amounts: [{name, grams, contribution}], feasible, reasons,
   alternatives }；verify(recipe) → 各成分实际含量与目标偏差（%），全部可单测。
2. 取整规则写死：先按理论值取整到 0.1g，再按总重优先微调（把差额补到占比最大的原料上），
   最终总重与目标总重的误差 ≤ 0.5%。测试覆盖一个会触发微调的例子。
3. 边界：目标含量之和 > 100%、某原料最小可称量 > 理论用量（取最小值并标注偏差，或标不可行）、
   原料重复、pH 目标无法满足。
4. 输出配比单：原料、克数、贡献的活性成分、占总重比例（保留 2 位小数），以及每步计算的算式说明
   （人工复核要看懂）。
5. 金额用分（整数）表示成本；确定性：同一输入跑两次结果一致。

界面：目标输入区 + 配比单表格 + 偏差校验区（含算式展开）；能导出配比单 CSV。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写计算与取整规则。

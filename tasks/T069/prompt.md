我记账老断，想做个简单记账本：分类预算、月度汇总、超支提醒，还能导入银行导出的 CSV。

模型（samples/transactions.csv 是银行导出流水，data/budgets.json 是分类预算）：

- 流水：日期、摘要、金额（有正有负）、对方、卡号后四位
- 分类：规则表（关键词 → 分类），比如 "咖啡|奶茶" → 餐饮、"地铁|滴滴" → 交通；
  导入时按规则自动分类，未命中的进"未分类"

要做的：

1. 纯逻辑：
   - `parseCsv(text)`：容忍逗号/引号/CRLF、金额写成 `-1,234.56` 或 `1 234.56` 或 `(1234.56)`（负数）、
     日期有 `2026-06-01` 与 `06/01/2026` 两种格式
   - `categorize(tx, rules)`：按规则分类，命中多个取"关键词最长"的规则；未命中给 uncategorized
   - `dedupe(txs)`：同一天 + 同金额 + 同对方视为重复（保留第一条并记录丢弃数）
   - `monthly(txs, budgets)`：按分类汇总本月支出/收入，与预算比较，超支项要给出超出金额与比例
2. 金额一律用分（整数）表示，输入里的浮点要按字符串解析再转，避免 0.1+0.2 这类误差。
3. 边界：空文件、只有表头、金额为 0、跨年数据（按年+月分组）、预算为 0（任何支出都算超支）、
   规则表为空。
4. 输出：月度看板（分类 × 预算 × 实际 × 差额）、未分类清单、重复丢弃清单、
   按日累计支出曲线（用于看花得快不快）。
5. 确定性：同一份 CSV 跑两次结果一致。

界面：导入区（粘贴或选文件）+ 分类看板（超支标红）+ 未分类清单（可手动指派分类，指派后立刻重算）+
导出汇总 CSV。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写分类规则与金额解析口径。

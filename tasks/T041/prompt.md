我们园区停车收费一直手工算，老出错，想做成一个能复算的计费模块 + 一个查询页面。

规则（data/rates.json 是费率表，samples/sessions.json 是几辆车进出记录）：

- 白天（08:00-20:00）首小时 6 元，之后每小时 4 元；夜间（20:00-08:00）每小时 2 元
- 不足 1 小时按 1 小时算；进场 15 分钟内出场免费
- 单日封顶 60 元（按自然日分别封顶，跨天的停车要拆成多天分别算再相加）
- 月卡车辆在有效期内免停车费（但要记录实际时长）；月卡过期按普通车算
- 每个自然日的费用要单独列出（时段明细：白天几小时、夜间几小时、各自金额）

要做的：

1. 计费纯函数：`calcFee(entry, exit, card)` → { total, days: [{date, dayHours, nightHours, amount, capped}], free }
   金额用分（整数），别用浮点。
2. 跨天分段要正确：比如 19:30 进场、次日 00:40 出场，要拆成两天分别计算（第一天 20:00 前半小时 + 半小时，
   第二天 40 分钟）。测试里至少覆盖 3 个跨天场景。
3. 边界：出门时间早于进场（报错）、正好 15 分钟（免费）、正好 1 小时（算 1 小时）、
   连续停 3 天（每天都要封顶判断）、月卡当天过期。
4. 同一份输入跑两次结果一致；时长换算全部按分钟算，最后再向上取整到小时。

界面：输入车牌 + 进出时间，列出分段明细和总费用；再给一个列表页看所有记录。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。怎么跑/怎么测写在 README 里。

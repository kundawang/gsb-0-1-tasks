想做个贷款试算器：算等额本息、等额本金，还要能算提前还款（含违约金）后的结果。

模型（samples/loans.json 是几笔贷款与提前还款方案，data/config.json 是计算参数）：

- 贷款：本金（元）、年利率（%）、期数（月）、还款方式（equal_installment=等额本息 / equal_principal=等额本金）
- 提前还款方案：第 N 期后一次性还 X 元，两种处理方式：
  - `reduce_months`：月供不变，缩短期数
  - `reduce_payment`：期数不变，减少月供
- 违约金：按提前还款金额的 p%（配置里给，默认 1%）收取，计入当期

要做的：

1. 纯逻辑：`schedule(loan)` → 逐月摊还表（期数、月供、本金、利息、剩余本金）；
   `prepay(loan, plan)` → 提前还款后的新摊还表 + 对比（省了多少利息、少了几期、总支出变化）。
2. 计算口径写死：月利率 = 年利率 / 12 / 100（不按天数）；金额用分（整数）逐月计算，
   等额本息月供公式 M = P × r × (1+r)^n / ((1+r)^n − 1)，四舍五入到分；
   最后一期用剩余本金结清（尾差归到最后一期，保证本金合计等于贷款本金）。
3. 等额本金：每月本金 = P / n（按月取整，尾差放最后一期），利息 = 剩余本金 × 月利率。
4. 边界：期数为 1、利率为 0（也要能算，月供 = 本金 / 期数）、提前还款金额大于剩余本金（只扣剩余并说明）、
   第 1 期就提前还、提前还款后月供小于 1 分（直接结清并说明）。
5. 校验：摊还表本金合计 == 贷款本金（尾差处理正确）、利息合计与公式推算误差 ≤ 1 分；
   同一输入跑两次结果一致。

界面：贷款参数输入 + 逐月摊还表 + 提前还款对比卡片（省息/缩短期数）+ 利息构成图（本金 vs 利息堆叠条）。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写公式与尾差处理。

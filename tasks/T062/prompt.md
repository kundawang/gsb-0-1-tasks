想做个游泳训练小工具：输入一组成绩和时间，算配速、SWOLF、划频，还要能换算短池和长池。

输入（samples/sets.json 是几组训练记录）：

- 记录：距离（25/50/100/200/400/800/1500 米）、时间（秒，精确到 0.01）、泳池长度（25 或 50 米）、
  划水次数（一趟里的总划次）、泳姿
- 要算的：
  1. 配速（每 100 米用时，秒，保留 2 位小数）与每 50 米用时
  2. SWOLF = 单趟用时（秒）+ 单趟划次（每 25 米或每 50 米都算，按池长归一）
  3. 划频（stroke rate，次/分钟）= 划次 ÷ 时间 × 60；划幅（distance per stroke，米/次）
  4. 短池/长池换算：用给定的换算系数（50 米池成绩 ≈ 短池成绩 × 1.02，系数可配置）双向换算
- 还要有训练区间：给定有氧阈值配速与无氧阈值配速，把每组记录标成 恢复/有氧/阈值/无氧 四档

要做的：

1. 纯逻辑：`analyze(record, config)`、`convert(record, fromPoolLen, toPoolLen, factor)`、
   `classify(paces, thresholds)`；全部可单测（`node --test`）。
2. 数值口径写死：时间按秒存、显示时转成 `1:23.45` 格式；所有中间计算用秒；四舍五入到 0.01 秒。
3. 边界：时间为 0（报错）、划水次数为 0（SWOLF 只算时间并提示）、距离不是池长整数倍、
   换算后往返回来误差 ≤ 0.05 秒（测试断言）、阈值没配（只算不分类并说明）。
4. 汇总：每档的组数/总距离/平均配速；训练量曲线（按组序列）。
5. 确定性：同一份输入跑两次结果一致。

界面：录入表格 + 分析结果表（配速/SWOLF/划频/划幅/档位）+ 换算器 + 训练量曲线。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写公式、单位与取整口径。

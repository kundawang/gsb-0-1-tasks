药房出库要按效期先进先出，还想提前预警临期药，想做个 FEFO 出库工具。

模型（samples/batches.json 是各批号库存，data/config.json 是预警阈值）：

- 批号：drug_code、batch_no、效期（YYYY-MM-DD）、库存数量、货位、是否已冻结（不允许出库）
- 出库申请：drug_code、数量、申请人、日期
- 规则：
  1. 同一个药按效期升序（FEFO）扣减；同效期按批号字典序
  2. 冻结批次跳过；过期批次（效期 < 出库日）不允许出库，要报存在过期批次需处理
  3. 库存不足时：能发多少发多少，剩下列为欠货（不自动拆到其他药）
  4. 临期预警：效期距今天 ≤ 90 天 → 预警；≤ 30 天 → 严重；≤ 7 天 → 紧急

要做的：

1. 纯逻辑：pick(batches, request) → { picks: [{batch_no, qty, expiry}], shortage, warnings }；
   alerts(batches, today) → 按期分级的预警清单；全部可单测。
2. 日期计算按自然日（不算小时），跨月跨年要正确；测试覆盖 2026-02-28 到 2026-03-01 这种边界。
3. 边界：同一药多批同效期、全部冻结、出库当天正好过效期（算过期）、数量为 0、申请数量超总量。
4. 输出：出库明细（批号 × 数量 × 效期）、欠货清单、预警清单（分级排序）、
   以及该药剩余库存的效期分布。
5. 确定性：同一份库存 + 同一申请跑两次结果一致（含批号顺序）。

界面：出库单录入 + 分配结果卡片（每批号数量）+ 库存效期分布图 + 预警看板（三色分级）。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写 FEFO 顺序与分级口径。

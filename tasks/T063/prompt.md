想做个五子棋对局复盘工具：给一盘棋的落子序列，判断谁赢、有没有漏掉的必胜点，并做简单 AI 对抗。

模型（samples/games.json 是几盘棋的落子序列）：

- 棋盘 15×15，坐标用 `H8` 这种（列 A-O、行 1-15），黑白交替落子，从黑开始
- 落子序列里可能出现非法落子（重复落点、超范围、赢了之后还继续下）→ 要标出第几步非法并停止回放

要做的：

1. 规则内核（纯逻辑）：
   - `replay(moves)` → 每步的棋盘快照 + 是否成五（横向/纵向/两个斜向）+ 胜负
   - `findWinningMoves(board, color)` → 当前该谁走，列出所有能立刻成五的点（去重、按行列排序）
   - `detectMissedWin(moves)` → 回放中如果某一步本来有必胜点却没走，记录"漏杀"（步号、应走的点）
2. AI：`bestMove(board, color, depth)` 用 minimax + alpha-beta（深度 2~4，可配置），
   评估函数：自己成五 +100000、挡住对方成五 +10000、活三/活四加权；
   必须只依赖棋盘状态（同一局面同 depth 结果一致，不引入随机）。
3. 边界：空棋盘（返回天元）、双方都无威胁（返回评估最优且坐标最小的点）、
   盘面已有五连（拒绝继续并给出胜负）、深度 0（只做规则判定）。
4. 性能：在只剩 20 个空点的局面上，depth=4 要在 2 秒内出结果（给宽松上限，别无限递归）。

界面：棋盘可点击落子，能加载样例序列逐步回放（上一步/下一步），显示"漏杀"标记与 AI 建议点。
约束：原生 ES module + HTML/CSS，不引依赖、不联网、不构建。README 写评估函数与搜索深度说明。
